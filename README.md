# HR Analytics Dashboard — Power BI

## Project Overview

This project is an HR analytics dashboard created using Microsoft Power BI.

The dashboard was designed to explore employee data and present key HR metrics in a clear and interactive way.

## What I Worked On

- Data cleaning and preparation
- Data modeling
- Creating relationships between tables
- DAX measures
- KPI calculations
- Interactive dashboard design
- Data visualization
- HR data analysis

## Analysis

The dashboard provides insights into different aspects of the workforce, including:

- Employee headcount
- Employee demographics
- Department analysis
- Job roles
- Employee status
- Salary-related information
- Workforce distribution

## Dashboard

The Power BI dashboard uses interactive visuals and filters to allow users to explore the HR data from different perspectives.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Project Purpose

This project was created as part of my practical Data Analysis learning journey to practice working with HR data and building interactive dashboards in Power BI.
